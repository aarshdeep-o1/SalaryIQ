# 💼 SalaryIQ Pro — Career Intelligence Platform

> 🚀 A data-driven career analytics platform built for Indian freshers to predict salaries, analyze skill gaps, and plan their career journey with confidence.

---

## 📌 About The Project

**SalaryIQ Pro** is a smart career intelligence web app that helps fresh graduates in India understand their market value, identify skill gaps, and get personalized salary negotiation guidance — all powered by real Indian job market data and analytics.

Built as a **Data Science / Data Analytics** project showcasing end-to-end skills from data modeling to interactive visualization and AI-style chatbot integration.

---

## ✨ Key Features

### 🎯 Profile Input Engine
- College tier selector — IIT / NIT / State / Private
- CGPA slider (0–10)
- City selection across major Indian metros
- Multi-skill selector — Python, SQL, Power BI, Excel, ML, Tableau, Java, React
- Projects, internships & certifications count

### 📊 Smart KPI Dashboard
- 💰 Predicted salary range based on your profile
- 🏆 Hire-ability Score out of 100
- 📈 Market Rank Percentile — "You're better than 74% of freshers"
- 🔖 Profile Strength Badge — Weak / Average / Strong / Elite

### 📉 Data Visualizations
- Bar chart — Salary by skill comparison
- Radar chart — Your profile vs top hired fresher
- Line chart — Salary growth at 1 year, 3 year, 5 year timeline

### 🧠 Skill Gap Analyzer
- Top 3 skills to add for maximum salary hike
- Expected % salary increase per skill added
- Personalized learning roadmap suggestions

### 🤖 LinkedIn Career Chatbot
- AI-style chatbot trained on Indian job market insights
- Answers 15+ real career questions like:
  - *"How do I negotiate my salary?"*
  - *"Is my CGPA good enough?"*
  - *"Which skill should I learn first?"*
  - *"How to write a LinkedIn headline?"*
  - *"Am I underpaid for my role?"*
- Smart fallback responses for custom queries

### 💬 Salary Negotiation Coach
- Personalized negotiation script based on your profile
- Quote range — exact number to say in interview
- Walk-away number — minimum you should accept
- Red flags — what NOT to say during negotiation
